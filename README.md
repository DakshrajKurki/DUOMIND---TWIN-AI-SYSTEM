# DuoMind — Personal Decision Intelligence

**Team XYNOVA · GATEWAYS 2026 · Domain 3: Personal Productivity & Lifestyle**

DuoMind builds a *Decision Twin* of you. It learns your goals, constraints and decision style, simulates each option you're weighing (1,000 Monte Carlo futures), explains its recommendation with tagged evidence, and learns from what actually happened.

- **Live site:** https://duomind-steel.vercel.app
- **Status check:** https://duomind-steel.vercel.app/api/gemini shows whether the Gemini key works
- **Repository:** https://github.com/DakshrajKurki/DUOMIND---TWIN-AI-SYSTEM

---

## Quick start

**Just run it:** double-click `index.html`. It opens in Chrome, Edge or Safari and works offline, because all libraries are embedded. Click **"Continue as guest — no sign-up"** to explore a Twin with sample data (it resets each visit).

**Turn on AI when running locally:** open **Settings → AI engine**, paste a Gemini API key (from https://aistudio.google.com/apikey) and click **Save & test**. The key stays only in your browser. Without a key, the app uses its built-in offline engine.

## Making changes

1. Edit the files in `src/`.
2. Rebuild: in Terminal, open this folder and run `node build.js` (or `npm run build`). Requires Node.js 18+. No `npm install` is needed.
3. Open `index.html` to check your change.
4. Commit and push both `src/` and the new `index.html`. Vercel redeploys automatically.

## Deploying (Vercel)

The live site is already set up. For a fresh deployment:

1. Push this folder to a GitHub repository. **Never commit a key.**
2. On vercel.com: **Add New → Project**, import the repo, set Framework Preset to **Other**, then **Deploy**.
3. In the project's **Environment Variables**, add `GEMINI_API_KEY` = your key (type **Secret**, Production).
4. **Deployments → ⋯ → Redeploy.**

On the live site, the browser calls `/api/gemini`; the server adds the key and forwards the request to Google. Visitors never see the key.

Optional environment variables: `ALLOWED_ORIGINS` (sites allowed to use the proxy), `RATE_LIMIT` (requests per visitor per 10 minutes, default 40) and `GEMINI_MODELS` (allowed model names).

## How it works

- **Understand:** AI (or the offline parser) extracts facts, goals and options from what you type.
- **Score:** each option gets impact, goal fit, downside risk, effort, reversibility and speed to value, plus behavioral fit from your Decision DNA.
- **Simulate:** 500 Monte Carlo runs per option. Weights come from your risk comfort, available hours and traits. A robustness check re-runs with ±15% noise 300 times and marks the pick **Robust** or **Fragile**.
- **Explain:** evidence is tagged SAID / DID / INFERRED / PREDICTED. The AI writes the explanation but cannot change the pick or the numbers.
- **Learn:** logging a real outcome updates six DNA traits, their confidence, and the Twin's prediction accuracy. The brain map lights up the traits involved.

**AI engine order:** Claude (when opened inside Claude) → Gemini (browser key, or the server proxy on Vercel) → offline engine.

## Security rules

- **Never** put a Gemini key in `config.js` or any committed file. GitHub's secret scanning will block it, and a public repo would expose it.
- The key lives only in Vercel's Environment Variables, or in a single browser's Settings.
- If a key ever leaks, delete it at https://aistudio.google.com/apikey and create a new one.

## Privacy and limits

- Accounts and Twin data are stored in the browser (localStorage). Passwords are saved only as salted SHA-256 hashes. There's no database, so data doesn't sync across devices.
- The proxy's rate limit is per server instance (best effort).
- DuoMind gives guidance, not professional medical, legal or financial advice.
- **Roadmap:** server-side accounts and database, multi-device sync, and a shared rate-limit store.
